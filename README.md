# Orientador Social, Território e Transformação

Repositório do e-book de Carlos André Tavares de Lima.

## Publicação no GitHub Pages
1. Envie `index.html` e o arquivo PDF para a raiz do repositório.
2. Em **Settings > Pages**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

O `index.html` abre o PDF diretamente dentro da página e também oferece botões para abrir e baixar o e-book.
